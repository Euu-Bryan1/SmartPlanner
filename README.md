# 📱 SmartPlanner

Aplicativo mobile desenvolvido em formato de protótipo utilizando Figma, com foco em organização de tarefas e usabilidade.

---

## 📌 Sobre o Projeto

O SmartPlanner é um projeto acadêmico voltado para a prototipagem de um aplicativo mobile de organização pessoal.  

A proposta do projeto é simular o funcionamento de um sistema real, permitindo que o usuário realize cadastro, login e gerenciamento de tarefas em uma interface intuitiva e organizada.

O projeto foi desenvolvido com foco em modelagem de requisitos, estruturação de sistema e aplicação de conceitos de UX/UI.

---

## 🎯 Objetivo

Criar um protótipo navegável que represente o funcionamento de um aplicativo real, aplicando:

- Análise de requisitos  
- Modelagem de sistema  
- Organização de fluxo de navegação  
- Estrutura de banco de dados (conceitual)  

---

## 📱 Funcionalidades

- Cadastro de usuário  
- Login  
- Criação de tarefas  
- Edição de tarefas  
- Exclusão de tarefas  
- Visualização de perfil  
- Navegação entre telas
